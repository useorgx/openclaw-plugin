# LinkedIn Carousel Performance Audit (B2B SaaS / Dev Tools)

Date: 2026-02-19  
Scope: Hook research and content strategy input for OrgX LinkedIn carousel production.

## 1) What current benchmark data says

- Socialinsider's 2025 LinkedIn benchmark study reports carousel posts as the top format by average engagement rate in their dataset, and indicates this pattern is strongest in business-oriented audiences.
- Metricool's 2025 LinkedIn study also ranks document/carousel-style posts among the best performers for interaction rate versus single-image and link-first formats.

Sources:
- https://www.socialinsider.io/social-media-benchmarks/linkedin
- https://metricool.com/linkedin-study/

## 2) Strategic implications for B2B SaaS/dev tools

- Prioritize carousels for mid-funnel education and problem framing.
- Use text-first hook slides before product UI slides; UI-first starts are weaker at stopping scroll.
- Keep each deck focused on one operator problem and one promised outcome.
- Package proof quickly (slide 2-4): benchmark, before/after, or workflow delta.
- Close with a single CTA type per post (comment keyword, DM intent, or link in comments), not mixed CTAs.

## 3) High-performing hook patterns to test

1. Contrarian: "Most teams automate the wrong step first."
2. Cost-of-inaction: "Your handoff is costing 6+ engineer-hours/week."
3. Teardown: "We rebuilt [workflow] in 7 slides."
4. Artifact-led: "Steal this runbook/checklist/template."
5. Decision framing: "Choose A if speed matters, B if control matters."

## 4) Carousel production guardrails (Larry playbook alignment)

- Slide 1: one sharp claim, <= 14 words, no jargon.
- Slide 2: tension/problem quantification.
- Slides 3-6: workflow + proof + objection handling.
- Final slide: one CTA and one clear next action.
- Target 6-9 slides for retention; avoid dense walls of text.
- Ensure each slide stands alone for mobile readability.

## 5) 30-day test matrix

1. Test variable: hook type (contrarian vs teardown vs artifact-led)  
   KPI: saves/post and comments/post
2. Test variable: proof format (numeric benchmark vs short case snippet)  
   KPI: completion proxy (last-slide impressions / first-slide impressions)
3. Test variable: CTA type (comment keyword vs DM vs link-in-comment)  
   KPI: qualified inbound conversations

Cadence:
- 2 carousel posts/week for 4 weeks (8 total)
- Keep publishing windows constant for cleaner comparison
- Weekly retro: keep top hook family, drop bottom one

## 6) Decisions for next content sprint

- Default LinkedIn pillar format to carousel for educational thought leadership.
- Build first 8-post sequence around "workflow teardowns" + "artifact-led" hooks.
- Track saves, comments, inbound DMs, and attributed demo/meeting starts in one sheet.
