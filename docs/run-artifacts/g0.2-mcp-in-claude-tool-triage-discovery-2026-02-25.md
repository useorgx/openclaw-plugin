## Demo Script (single pass)

### Phase 0: G0.1 connection smoke (2-3 minutes)
1. Connect Claude to scoped MCP endpoint for target persona (example: `design`).
2. Call `orgx_status`.
Expected: JSON payload with active initiatives/agents/tasks and no transport error.
3. Call `orgx_sync` with empty memory payload.
Expected: structured response, no schema/validation errors.

### Phase 1: Read/report flow (all domains)
1. Call `list_agent_configs` then `get_agent_config` (default id).
Expected: deterministic config object and checksum metadata.
2. Call `orgx_report_progress` with a non-destructive summary.
Expected: success response, activity emission acknowledged.
3. Call `orgx_register_artifact` with local test artifact metadata.
Expected: artifact registration success and retrievable identifier.
4. Call `orgx_spawn_check` against a sample task/domain.
Expected: allowed/denied result with explicit rationale.
5. Call `orgx_request_decision` with `blocking=false` test prompt.
Expected: decision object created (or clear policy rejection) with machine-readable output.

### Phase 2: Elevated flow (operations/orchestration only)
1. Repeat connection against `operations` scope.
2. Call `update_agent_config` with a reversible, low-risk update (for example `frozen=true` in a sandbox org).
Expected: updated config response with version/checksum change.
3. Call `orgx_reassign_stream` on a non-critical test workstream.
Expected: reassignment acknowledgement including target domain/assignee metadata.
4. Call `orgx_apply_changeset` with one minimal mutation operation.
Expected: idempotent accepted response and operation-level result summary.

## UX Pass/Fail Rubric (Claude operator perspective)

### Pass criteria
1. Every tool call returns structured JSON with predictable top-level fields.
2. Error responses are action-guiding (missing parameter, scope denied, auth missing) rather than opaque.
3. Scoped endpoint behavior is obvious: elevated tools are absent/denied outside operations/orchestration.
4. Demonstration can be completed end-to-end without leaving Claude chat context.

### Fail indicators
1. Tool list mismatch between declared scope and runtime behavior.
2. Success responses without actionable identifiers (run id, decision id, artifact id, checkpoint id).
3. Repeated need to switch to unscoped endpoint for routine flows.
4. Any response shape drift that breaks scripted parsing between steps.
